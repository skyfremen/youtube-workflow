# YouTube Story Bot — Wacky Dramas

This is an isolated clone of `youtube-shorts-bot` for the new Wacky Dramas story format. The original shorts bot remains untouched.

Differences: original story-first content schema, Kokoro TTS narration, branded story card, phrase-following subtitles, visually engaging reusable background footage, and persistent `@WACKYDRAMAS` handle at the bottom.

Run a local render with `python youtube-story-bot/render.py` after installing requirements. A dedicated manual test workflow renders a 10-second artifact without publishing to YouTube.
