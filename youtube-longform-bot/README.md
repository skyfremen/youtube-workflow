# Wacky Insights Long-form Bot (MVP)

This folder is intentionally separate from `youtube-shorts-bot/`.

## Goal
Render a 60-second, 1920x1080 animated explainer as a proof of concept before scaling the same engine to 8-10 minute videos.

## MVP characteristics
- Remotion + React renderer
- Original programmatic shapes; no borrowed visual assets
- 8 scenes totaling exactly 60 seconds
- Free local narration generated by `espeak-ng` in GitHub Actions
- No YouTube upload, no scheduling, no production trigger
- Manual GitHub Actions workflow only

## Files
- `content/demo-plan.json` - scene plan and narration
- `scripts/validate-plan.mjs` - fail-closed plan validator
- `src/index.jsx` - Remotion renderer
- `public/narration.wav` - generated only during CI and not committed
- `output/demo.mp4` - generated only during CI and uploaded as a temporary artifact

## Safety boundary
The MVP must not read, write, import, or execute files from `youtube-shorts-bot/`. The workflow contains an isolation check before rendering.

## Next stages after the 60-second test passes
1. Improve voice quality while retaining a zero-cost fallback.
2. Add a reusable asset registry for characters, poses, backgrounds, props, icons and SFX.
3. Generate scene timing from measured narration audio.
4. Expand to 3 minutes, then 8-10 minutes.
5. Add a separate long-form planner/archive/analytics flow.
6. Only after explicit approval, add YouTube private upload and scheduled publishing.
